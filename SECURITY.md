# Reporting problems

For parser correctness bugs use an invented minimal reproduction. Never include
customer files, extracted project data or private source paths in public reports.
Do not disclose exploit details in a public issue. Use the repository's private
security advisory reporting option when available. If no private reporting option
is available, do not post sensitive details publicly. No security response time or support SLA is promised.

The parser enforces structural and size limits. Hosts remain responsible for
process memory/CPU/time limits, access control and handling potentially large
outputs. This package is not a service and does not fetch external dependencies
or execute archive comments.
